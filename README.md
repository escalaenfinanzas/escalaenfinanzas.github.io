# Escala En Finanzas — Sitio web V1

Primera versión estática y responsive de escalaenfinanzas.com.

## Archivos
- `index.html`: estructura y contenido.
- `styles.css`: diseño, colores y adaptación móvil.
- `script.js`: menú móvil y animaciones.
- `assets/`: logo, banner y favicon.

## Cómo revisarla
Abre `index.html` en Chrome, Edge o Firefox.

## Publicación recomendada
1. Crear una cuenta o repositorio en GitHub.
2. Subir todos los archivos conservando la misma estructura.
3. Activar GitHub Pages desde la configuración del repositorio.
4. Probar primero con la dirección temporal de GitHub.
5. Conectar `escalaenfinanzas.com` mediante los registros DNS del dominio.
6. No borrar ni modificar los registros MX, SPF, DKIM o DMARC de Google Workspace.
